# 像素奶蛙数字博物馆 · 公开投稿

个人和团队都可以给博物馆投稿。登录 GitHub，选择下面的入口即可。组织外的作者也可以提交和跟进自己的稿件。

| 我想做什么 | 从这里开始 |
| --- | --- |
| 展示自己创作或参与创作的作品 | [提交作品](https://github.com/NaiwaPixel/museum-intake/issues/new?template=submission.yml) |
| 推荐一件公开作品，或提出一个选题 | [推荐内容](https://github.com/NaiwaPixel/museum-intake/issues/new?template=suggestion.yml) |
| 看编辑回复、补充预览或更正署名 | [查看投稿记录](https://github.com/NaiwaPixel/museum-intake/issues) |

像素插画、游戏、动态壁纸、表情、短片、声音作品和制作工具都欢迎。投稿时写下作品名、公开署名，并附一张预览、一个试玩地址或一段试听。推荐他人的作品时，请贴作者公开发布的页面。

**提交的文字、评论和附件对所有人可见。** 只放你和合作者愿意公开的预览。原始工程和个人联系方式可以留在自己手里。

## 提交后

每份投稿都有自己的 Issue 编号。编辑会在该页回复，你可以随时用评论补充或申请撤下官网展示。标签「待审」「待补充」「已采纳」「已入藏」记录处理进度。入藏后，编辑会贴出官网作品页。

作品按作者确认的署名、展示范围和使用条件收录。是否提供原文件下载由作者单独决定。推荐作品时，编辑会先向作者确认展示意愿。
